# 1.2.13
Extending a recorded session now starts the new shell with a clean terminal.
- The previous program's terminal modes (mouse tracking, alternate screen, bracketed paste, keyboard modes and the like) are switched off when a session is extended, so viewers no longer send mouse reports to a shell that never asked for them
- The screen text is kept, and the cursor lands where the new shell expects it
- Live sessions you attach to are unchanged: the program that set those modes is still running there

1. **U1 is only half tested (hard row).** The row covers Ctrl+D "in a live session, *or on a session that cannot be resumed (joined, pending)*". `R3_delete_key.sh` tests only the live shell running `cat`. No script makes a joined or pending session and presses Ctrl+D on it. The "never delete" promise for those sessions is unchecked.
2. **R7 is attributed to the wrong script for Ctrl+D.** The row lists `R6_search_states.sh`, but Ctrl+D during search, both cancel and confirm, is checked only in `R3_delete_key.sh` (`in_box` after each). It is covered, just not where the row says. R8's "Ctrl+D deletes" in search is likewise covered only by R3.
3. **R6 checks highlights only indirectly.** The third-state check is `sectionsDrawn and terminalFocused`. `in_terminal` checks that the box is empty and sections are not drawn. Nothing directly asserts that the name filter is gone (all rows listed again) or that the match highlights in the terminal are cleared once focus is in the terminal. Sections are checked directly.
4. **R1 times only Ctrl+PgDn among the switch keys.** Ctrl+PgUp is used only in the A-B-A correctness step and is never timed. The row says "Ctrl+PgUp/PgDn", so this is minor.
5. **"No perceptible wait" (R1, R2) is graded on medians plus the longest-task limit.** Single maxima are printed but not asserted: switch max 117.3 ms and many-profiles max 96.5 ms are within their limits, but the quiet echo max was 126.5 ms, against a 30 ms median threshold.
